# Hoja de Vida en React Native (Expo)

App móvil de hoja de vida con 4 pantallas (Datos Personales, Estudios, Experiencia y Hobbies) navegables con Bottom Tabs.

## Requisitos
- Node.js, Expo Go en el celular

## Cómo ejecutar
npm install @expo/ngrok@^4.1.0
npx expo start --tunnel ngrok

## Estructura
- src/app: pantallas y menú de pestañas (_layout.tsx)
- src/components: MiBoton, TarjetaEstudio, TarjetaExperiencia, TarjetaHobby
